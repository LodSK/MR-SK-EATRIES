# PURPOSE

This document defines the permanent engineering constitution governing the design, development, testing, deployment, maintenance and future evolution of the MR_SK EATRIES Enterprise Restaurant Platform.

Every AI agent, software engineer, contributor or automation system working on this project shall comply with this constitution before modifying any part of the codebase.

This document has higher priority than any sprint instructions.

---

# PROJECT VISION

MR_SK EATRIES shall become one of the highest quality restaurant management and online ordering systems built using AI-assisted software engineering.

The finished product must be comparable to international restaurant platforms in terms of

• User Experience

• Performance

• Security

• Scalability

• Maintainability

• Architecture

• Documentation

• Enterprise Readiness

This project is NOT a portfolio toy.

It must resemble a real commercial SaaS restaurant platform.

# QUALITY STANDARD

Every feature shall satisfy all of the following before being considered complete

The backend works

The frontend works

The feature is connected

The feature has validation

Errors are handled

Loading states exist

Success states exist

Responsive behaviour exists

Dark mode compatibility exists where applicable

Accessibility has been considered

The feature has been tested

The feature has been documented

If any item is missing

The feature is NOT complete.
