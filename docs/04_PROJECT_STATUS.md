# Project Status

**This file is intentionally a pointer, not a duplicate.** The real, actively-maintained status document is `PROJECT_STATUS.md` at the repository root — it has been the single source of truth since the Foundation Recovery sprint and is updated at the end of every sprint with real, verified detail (sprint-by-sprint build history, known blockers, known limitations, technical debt, verification performed).

Read `../PROJECT_STATUS.md`.

**Why this file was empty until Sprint 16, and why it stays a pointer rather than becoming a second copy:** this `docs/00`–`docs/14` numbered set was introduced alongside a newer engineering charter (`02_MASTER_PROMPT_V2.md`) that assumes it as the canonical location, but the root file already existed, was already authoritative, and was already hundreds of lines deep with real sprint-by-sprint history. Duplicating that content here in full would immediately start drifting the moment either copy was updated and the other wasn't — a worse outcome than one file with a clear pointer. If a future sprint wants to formally migrate the root file's content into this location, that's a real decision (and a genuine content move, not a copy) that should be made deliberately, not as a side effect of a routine status update.
